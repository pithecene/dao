## 4. Reading the matrix

- **Tier B-Bootstrap** is the set of constructs in §1 whose lowering the
  bootstrap rejects in §3, plus the prelude functions in §2 the bootstrap
  cannot yet compile.  Everything else in the Tier B backlog can follow
  the first bootstrap crossing.
- A stage with zero diagnostics on every program is closed for the corpus.
- The first blocking diagnostic names the construct to implement next for
  that stage; rerun the audit after each slice.
